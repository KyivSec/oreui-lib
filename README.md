# OreUI Lib

A client-side UI library for **Minecraft 1.21.1 / NeoForge**, inspired by the Ore UI design system. It helps mod developers build consistent menus, screens, and HUDs using Minecraft's native rendering and input systems.

## Features

- Reusable widgets: buttons, toggles, sliders, text fields, dropdowns, tables, cards, and color pickers.
- Flexible grid layouts, menu presets, scrollable screens, modals, and popups.
- HUD components, tooltips, navigation controls, and loading animations.
- 3D player and model previews, with optional Curios equipment integration.
- Pixel icons, configurable palettes, and custom UI font support.
